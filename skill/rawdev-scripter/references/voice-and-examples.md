## 1. Hook library

Pick ONE per script. Hinglish, 1-2 lines.

| Formula | Pattern | Example |
|---|---|---|
| Progression (Dev's signature) | "X toh tumne sikh liya, ab bari hai Y ki" | "Character toh tumne bana liya, ab bari hai uske 30 poses banane ki" |
| Secret leak | "Yeh secret app..." / "yeh feature tumse chupa rakha hai" | "Yeh secret app tumhe after effects wala tracking free mein deta hai" |
| Capability promise | "Tum [pro result] apne mobile se bana skte ho" | "Tum After Effects level ka face tracking apne mobile se bana skte ho" |
| Negative command | "Stop karo ... aise" | "Stop karo Veo 3.1 ko aise use krna" |
| Pain-point diagnosis | "Tumhara ... kyun nahi ... ho raha, yeh fix hai" | "Tumhara character har video mein alag kyun dikhta hai, yeh raha fix" |
| Contrarian obituary | "X dead hai / X jhooth hai" | "Professional editing paise se hoti hai, yeh jhooth hai" |
| Confession / plot twist | "Plot twist: ..." | "Plot twist: yeh video maine apne phone se banaya" |
| Contrarian case study | "Kam X, zyada Y" | use only if the brief has a real result |
| Vault tease | "Yeh 30+ ... mere paas ready hain" | "Yeh 30+ prompts mere paas ready hain, chahiye?" |
| Shock statistic | number + source | ONLY if the brief supplies both |

## 2. Script skeletons (from the audit)

- **Tutorial (most common here):** hook, literal taps, "bas hogya", keyword CTA.
- **Vault with open loop:** headline, sample items, "+N more" tease, keyword CTA.
- **Secret leak:** tease the secret app, show the taps, name the app via comment or pinned comment.
- **Confession and reframe:** plot-twist admission, cause, 3-step method.

## 3. CTA keywords in circulation

GROW, HUMAN, LENGTH, EDIT, RULES, FORMAT, TIMING, GPT, GUIDE, VIRAL, prompt. For tutorials prefer one-word, topic-specific keywords: prompt, app, studio, tracking, preset, veo.

What these show: progression hooks, literal taps, settings rattled off, "bas hogya", keyword-DM or pinned-comment CTAs, stretched sign-off. What they lack (fix in new scripts): a punchier first 3 seconds, a save prompt, a share prompt.

## 5. Gold-standard examples

Example A (progression hook, tutorial):
Character toh tumne bana liya, ab bari hai uske 30 different poses banane ki, woh bhi same face ke saath.

Sabse pehle Flow AI par aao, new project create krke + icon par tap krna, fir image upload krke apne character ki image daal do, ab library se apna character add krlo, fir apna pose describe krdo ya ChatGPT se prompt lelo, maine already prompt le rakha hai, yahan paste krke yeh setting rkhlo aur generate krdo, bas hogya.

Baki maine 30+ prompts ready rkhe hai, comment "prompt" aur main tumhe DM krdunga, isse save bhi krlo taaki baad mein kaam aaye, aur jisko character banana hai usko share krdo, follow bhi krlena, byeeeeeeee.......

Example B (capability promise, secret app):
Tum After Effects level ka face tracking effect apne mobile se bana skte ho, chalo batata hu kaise.

Sabse pehle is secret app par aana hai, fir + icon par tap krke apna video import krlo, ab niche stabilization wale option par tap krna hai, fir track par click krke yeh white circle apne character ki nose ya eyes par set krlo, track par click krdo, bas hogya.

Baki app ka naam chahiye toh comment "app" aur main tumhe DM krdunga, save krlo taaki baad mein bhool na jao, aur apne editor dost ko bhej do, follow bhi krlena, byeeeeeeee.......

Example C (studio + animate, progression):
